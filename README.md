# 🚀 CareerSphere - Ultimate Premium Job Portal & Recruitment Platform

An elite, world-class, production-quality Job Portal & Recruitment Platform named **CareerSphere**.
Built with a combination of a premium SaaS startup, modern recruitment platform, enterprise HR system, and high-end technology company.

---

## 🌟 Key Highlights & Engineering Features

### 1. Zero Build Steps / Instant Browser Ready
- All files are placed directly in the project root with **no subfolders**.
- **No Node.js, npm, or terminal build servers required**. Simply double-click `index.html` in any modern browser (Chrome, Edge, Firefox, Safari) or open it directly.

### 2. Premium Visual Identity & Design System
- **Sophisticated Color Palette**:
  - Midnight Navy: `#07111F`
  - Deep Blue: `#0B1F3A`
  - Electric Blue: `#2563EB`
  - Cyan: `#06B6D4`
  - Violet: `#7C3AED`
  - White: `#FFFFFF`
  - Soft Gray: `#F8FAFC`
- Intelligent gradients (`Electric Blue -> Cyan` and `Blue -> Violet`), soft ambient glows, dynamic card hover elevations, and modern glassmorphism.
- Complete **Dark / Light Mode** switcher with instant transition and persistence in `localStorage`.

### 3. Sticky Glass Navbar
- Brand logo with gradient career sphere icon.
- Interactive navigation links: `Home`, `Find Jobs`, `Companies`, `Career Resources`, `Candidate Portal`, `For Employers`.
- Search quick-trigger, notifications dropdown with unread badges, and responsive mobile drawer.

### 4. Interactive Hero & Multi-Parameter Search
- High-impact headline: *"Find Your Next Opportunity. Build Your Future."*
- Multi-field search box (keywords, location, work mode dropdown).
- Popular search chips (Software Engineer, Frontend Developer, UI/UX Designer, ML, Product Manager, DevOps).
- Floating glass preview cards with micro-animations.
- Trust statistics counters (**25K+ Active Jobs**, **8K+ Companies**, **120K+ Professionals**, **95% Hiring Success**).

### 5. Advanced Job Discovery & Multi-Facet Filtering
- Client-side real-time filtering across 24+ comprehensive positions:
  - Text search (title, company, description, skills)
  - Location input
  - Minimum salary range slider ($50K to $250K+)
  - Work Mode checkboxes (Remote, Hybrid, On-site)
  - Job Type checkboxes (Full-time, Contract, Internship)
  - Experience level checkboxes (Entry, Mid, Senior, Lead, Executive)
  - Industry selector dropdown
  - Skills tag cloud selector
  - Sorting (Most Relevant, Newest, Highest Salary, Lowest Salary)
  - View switcher: **Grid View** vs **List View**

### 6. Multi-Step Application System (6 Steps)
- **Step 1**: Personal Information (Name, Email, Phone, Location, Portfolio)
- **Step 2**: Verified Resume selection or upload
- **Step 3**: Cover Letter & custom introductory notes
- **Step 4**: Role screening questions (Years of experience, notice period, compensation expectation)
- **Step 5**: Comprehensive review summary
- **Step 6**: Confirmation screen with auto-generated Application ID (e.g. `CS-APP-88421`) and direct button to track application in candidate dashboard!

### 7. Candidate Dashboard & Application Tracker
- High-level metric cards (Active Applications, Interviews Scheduled, Saved Bookmarks, Profile Strength Meter: 92%).
- **Interactive Application Tracker**: Visual timeline (`Applied` -> `Under Review` -> `Shortlisted` -> `Interview` -> `Decision`) with filter tabs (*All, Interview, Shortlisted, Under Review, Applied*).
- **Saved Jobs**: Bookmarked jobs with 1-click apply and remove.
- **Recommended Jobs**: AI match score badges (98% Match) and match explanation.
- **Profile Builder**: Editable headline, bio, skills, experience, and contact details with instant save.
- **Resume Manager**: Upload simulated CV, preview modal rendering formatted document, and download.
- **Messaging System**: Split-pane recruiter chat with online indicators, conversation history, and real-time response simulation.

### 8. Employer Dashboard & Recruitment Portal
- Metrics overview (Active Jobs, Total Applications, Shortlisted, Interviews Scheduled, Conversion Rate).
- **Interactive SVG Recruitment Analytics**: Applications received over time bar chart and candidate source channel distribution, with interactive timeframe filters (`7D`, `30D`, `3M`, `1Y`).
- **Candidate Pipeline**: Filter applicants by job and status, view match %, skills, CV preview, Shortlist, and Schedule Interview.
- **Interview Scheduler Modal**: Set date, time, interview stage, and video link with automatic dispatch.
- **Post a Job Form with Live Preview**: Real-time side-by-side card preview updating dynamically as you type title, department, location, work mode, salary, skills, and description!
- **Manage Jobs**: Toggle listings between Active and Paused.
